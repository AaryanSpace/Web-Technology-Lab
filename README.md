# Web Technology Lab 🌐

This repository contains my practical assignments and lab experiments for the **Web Technology** subject. It showcases fundamental frontend development skills and advanced server-side backend integration using **HTML5**, **CSS3**, **JavaScript**, **PHP**, and **MySQL**.

## 📂 Projects & Experiments Included

### 1. Personal Portfolio Website 👤
A static personal website designed to showcase my profile, skills, and projects.
- **Tech Stack:** HTML5
- **Features:** Semantic structure, About Me section, and Contact details.

### 2. E-Commerce Website 🛒
A frontend prototype layout for an online shopping platform.
- **Tech Stack:** HTML5
- **Features:** Product grid structure and basic navigation setup.

### 3. Styling Personal Website 🎨
Applying modern design principles to the personal portfolio.
- **Tech Stack:** HTML5, CSS3
- **Features:** Modern styling, colors, typography, and responsive layouts.

### 4. Styling E-Commerce Platform 🛍️
Enhancing the e-commerce platform with advanced CSS techniques.
- **Tech Stack:** HTML5, CSS3
- **Features:** Responsive product cards, Flexbox layouts, and styled navigation bars.

### 5. Interactive Calculators 🧮
A collection of fully functional calculators built with logic and DOM manipulation. Includes Basic, Advanced (Glassmorphism), and Scientific versions.
- **Tech Stack:** HTML, CSS, JavaScript
- **Features:** Math evaluation, error handling, syntax highlighting, and CSS Grid.

### 6. Forms & JavaScript Validation 🛡️
Client-side form validation for robust user input handling.
- **Tech Stack:** HTML, CSS, JavaScript
- **Features:** Real-time regex validation, password strength meter, and error UI.

### 7. Event Handling 🖱️
Interactive web elements using JavaScript DOM events.
- **Tech Stack:** JavaScript
- **Features:** Mouse events (`onclick`, `onmouseover`), keyboard events, and dynamic DOM updates.

### 8. PHP Form Processing & Validation ⚗️
Server-side backend processing for secure data handling.
- **Tech Stack:** PHP, AJAX
- **Features:** Backend regex validation, input sanitization against XSS, and async JSON responses.

### 9. Product Management with Database 🗄️
Relational database design and dynamic UI rendering.
- **Tech Stack:** PHP, MySQL (PDO)
- **Features:** Database schema creation, prepared statements, and dynamic product fetching.

### 10. Sessions, Cookies & Shopping Cart 🔐
State management across multiple HTTP requests.
- **Tech Stack:** PHP Sessions, Cookies
- **Features:** Secure user authentication, persistent browser preferences, and `$_SESSION` array-based shopping cart.
